# Service-Level Objective Definitions

## Time basis

- Persist timestamps as UTC instants generated by the application.
- Convert timestamps to local time only for display.
- Durations use elapsed wall-clock time unless a future business-calendar policy
  explicitly excludes weekends, holidays, or off-hours.

## Per-category targets

An administrator can configure these targets independently for each category:

- Average time to claim.
- Average time in progress.
- Average reopen rate.

Configuration changes apply prospectively to SLO evaluation. Preserve the
target applicable to each lifecycle cycle or keep versioned configuration so a
later edit does not rewrite historical compliance.

## Metrics

### Time to claim

For a queue cycle:

`first assignment timestamp - queue-entry timestamp`

The initial queue-entry timestamp is submission time. A reopening starts a new
queue cycle at its reopen timestamp. Handoff does not start a new queue cycle and
retains the original queue-entry timestamp for that cycle.

Unclaimed incidents are excluded from completed average calculations but may
show a live countdown/overdue badge.

### Time in progress

For a completed resolution cycle:

`resolution timestamp - first assignment timestamp for that cycle`

An `ASSIGNED` incident is considered in progress immediately. There is no
separate `IN_PROGRESS` state or start-work action. The duration continues
through handoff and reassignment within the same resolution cycle.

### Reopen rate

For the selected filter and time period:

`number of resolved incidents reopened at least once / number of incidents resolved`

Count an incident once in the numerator even if it is reopened multiple times.
Also retain a separate reopen-event count for operational analysis.

## Attribution

- Resolution count is attributed to the responder assigned when the resolution
  occurred; admin-resolved cases are reported separately unless a responder was
  assigned.
- Time-to-claim statistics may be grouped by the responder who first claimed or
  was assigned the cycle.
- Reopen statistics may be grouped by the responder responsible for the
  immediately preceding resolution.
- Reporter filters must not reveal anonymous-reporter identity.

## Required edge-case tests

- Equal timestamps and zero durations.
- Multiple handoffs and reassignments.
- Reopen followed by another resolution.
- Incidents unresolved at the end of a reporting period.
- SLO target changes between lifecycle cycles.
- Empty result sets and division by zero.
- Timezone and daylight-saving display boundaries without changing durations.
